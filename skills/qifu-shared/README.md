# qifu-shared

Shared references used by the Qifu Figma page-generation skills. Install this package together with the `qifu-*` page skills so component maps, platform baselines, and theme variables stay in one place.

This is a dependency package rather than a page-generation workflow. Implicit invocation is disabled; page skills load its references directly.

Core contracts:

- `references/page-context.md`
- `references/component-invocation-baseline.md`
- `references/component-map.md`

Included platform baselines:

- `references/platform-yushu.md`
- `references/platform-zhikexing.md`
- `references/platform-generic.md`
